# X Follow Tracker

一个面向 X（原 Twitter）的本地 Chrome / Edge 扩展，用于扫描、比较和导出粉丝与关注关系。

当前版本：**1.1.0**

> 本项目与 X Corp. 无关联，也未获得其认可。X 和 Twitter 是其各自权利人的商标。

## 功能

- 扫描当前账号的粉丝和关注列表
- 筛选“未回关你”“你未回关”和“双方互关”
- 从第二次扫描开始识别期间取关和新增粉丝
- 按用户名或显示名称搜索
- 将当前分类导出为 CSV
- 支持多个 X 账号并分别保存历史快照
- 所有扫描结果仅保存在浏览器扩展存储中

## 隐私和权限

扩展不要求 X 密码，不使用 OAuth，不调用远程服务器，也不会自动关注或取关任何账号。

所需权限：

- `storage` / `unlimitedStorage`：在当前浏览器保存历史快照
- `activeTab`：响应用户点击扩展按钮
- `https://x.com/*`：在 X 页面展示面板并读取当前可见的关注列表

## 安装

1. 下载或克隆本仓库。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本仓库根目录。
6. 登录 `x.com`，点击浏览器工具栏中的扩展按钮。

## 使用

1. 输入自己的 X 用户名（通常会自动识别）。
2. 点击“一键扫描”。
3. 保持标签页打开，等待扩展依次扫描粉丝页和关注页。
4. 扫描完成后查看分类；以后再次扫描即可比较变化。

## 局限

- 第一次扫描只能建立基线，不能恢复此前发生的取关。
- X 使用动态加载；账号较多时扫描可能需要几分钟。
- 账号改名、注销、被冻结或暂时不可访问时，可能被识别为取关。
- X 页面结构发生变化后，扫描逻辑可能需要升级。
- 请自行遵守 X 的服务条款及所在地法律。
